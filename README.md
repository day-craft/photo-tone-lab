# 18 Pro Lab

아이폰 14 Pro로 찍은 사진을 **18 Pro의 밝고 자연스러운 톤**으로 바꿔 주는 웹앱입니다.
사진은 기기 안에서만 처리되고, 저장할 때 **원본 메타데이터(촬영일시·GPS·기기·렌즈·노출·Apple MakerNote)를 그대로** 새 사진에 담습니다.

- 정적 파일만으로 동작합니다 (HTML + CSS + JS, 빌드 없음)
- GitHub Pages / 어떤 정적 호스팅에도 그대로 올릴 수 있습니다
- 아이폰 Safari에서 홈 화면에 추가하면 앱처럼 열립니다 (PWA manifest 포함)

## 쓰는 법

1. 사진을 고릅니다 (사진 앱에서 바로, 또는 파일에서 HEIC/JPG).
2. 위아래로 갈라진 **비교 슬라이더**를 좌우로 밀어 원본과 보정본을 비교합니다.
3. 프리셋 4종 중 하나를 고르고, 필요하면 밝기·암부 복원·대비·색감·선명도를 더 조정합니다.
4. **사진첩에 저장**을 누르면 iOS 공유 시트가 열립니다 → “이미지 저장”을 누르면 사진 앱에 들어갑니다.
   공유가 막힌 환경에서는 **다운로드**로 파일을 저장합니다.

## 프리셋

| 프리셋 | 특징 |
| --- | --- |
| 18 Pro 표준 (화사함) | 그림자를 들어 올리고 중간톤을 밝게, 색은 담백하게. 기본값 |
| 실내·인물 (피부톤) | 하이라이트를 부드럽게 눌러 피부를 자연스럽고 따뜻하게 |
| 저조도·야간 (암부 복원) | 그림자를 크게 끌어올리고 색 노이즈를 정리 |
| 선명한 야외 (선명함) | 하늘 하이라이트를 지키면서 미세 대비와 색을 진하게 |

사진이 이미 밝게 찍혔다면 프리셋 강도를 자동으로 줄여 과보정을 막습니다.

## 메타데이터를 지키는 방식

- **JPEG 원본**: 원본 파일의 APP1(EXIF·XMP), APP2(ICC 프로파일), APP13(IPTC), COM 세그먼트를 그대로 뜯어
  새로 만든 JPEG의 SOI 뒤에 그대로 다시 넣습니다. EXIF 안의 Orientation만 `1`로, 픽셀 크기 태그만
  실제 저장 크기로 고칩니다. 나머지 바이트는 손대지 않으므로 Apple MakerNote도 원본 그대로입니다.
- **HEIC/HEIF 원본**: HEIF 컨테이너의 `Exif` 아이템을 꺼내 TIFF 블록(Apple MakerNote 포함)을 그대로
  APP1으로 감싸 넣습니다. 컨테이너 파싱이 실패하면 읽어 낸 값으로 표준 EXIF를 새로 씁니다.
- **저장 후 자체 검증**: 저장한 JPEG를 다시 파싱해 촬영일시·기기·렌즈·노출·GPS·MakerNote·Orientation을
  확인하고, 결과를 화면 ‘메타데이터’ 카드에 표시합니다.

## 파일 구조

```
index.html          화면
styles.css          스타일 (모바일 우선, 다크 스튜디오 톤)
js/exif.js          JPEG 세그먼트 파서·주입기, TIFF 리더/패처, HEIF Exif 추출, EXIF 생성기
js/engine.js        톤 엔진 (루미넌스 기반 톤 테이블, 클래리티, 채도, 노이즈 정리, 타일 렌더)
js/app.js           UI 로직 (불러오기·미리보기·비교 슬라이더·저장)
manifest.json       PWA 매니페스트
icon.svg            앱 아이콘
icons/              아이콘 PNG (192/512/maskable/apple-touch)
```

## 배포

GitHub Pages 기준:

1. 이 폴더의 파일을 저장소 기본 브랜치(`main`)에 올립니다.
2. 저장소 Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, 폴더 `/ (root)`.
3. `https://<사용자>.github.io/photo-tone-lab/` 로 열립니다.
4. 아이폰 Safari에서 열고 공유 → **홈 화면에 추가**하면 전체 화면 앱처럼 실행됩니다.

> GitHub Pages는 무료 플랜에서 **공개 저장소**만 배포됩니다. 비공개로 두려면 Pro 플랜이 필요합니다.

## 브라우저 지원

- iOS Safari 15.4+ (권장). `navigator.share({files})`로 사진 앱에 바로 저장할 수 있습니다.
- HEIC는 Safari가 기본으로 디코딩합니다. 디코딩이 안 되는 브라우저(데스크톱 크롬 등)에서는
  jsDelivr의 `heic2any`를 그때만 불러와 변환합니다 (인터넷 필요).
- 아주 큰 사진(48MP)은 Safari 캔버스 메모리 한계 때문에 최대 약 16MP로 줄여 저장하고, 화면에 그 사실을 표시합니다.
